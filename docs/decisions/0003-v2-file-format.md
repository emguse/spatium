# ADR 0003: version 2形式と旧形式非対応

- 状態: 採用
- 決定日: 2026-09-11
- 関連計画: [日付アンカーと存在期間への移行](../plan/date-anchored-timeline.md)

## 背景

旧形式は日付を持たず、任意の時点で出現・消滅・再登場できる。新形式の単一存在期間に正確に移すには、利用者による日付割り当てと再登場の整理が必要になる。

## 決定

保存形式をversion 2に変更し、version 1の読み込み・自動移行は提供しない。旧形式を選んだ場合は理由を説明し、作業中のプロジェクトを維持する。

新形式は背景・校正・グリッド・固定物と、開始日・終了日・日付付き位置キーフレームを持つ配置物を保存する。日付の実在性、期間、初期位置、日付の重複・順序、寸法、ID重複を検証してから置き換える。

## 代替案

- 全時点の移行ウィザード: 既存の成果を保持できるが、単一存在期間へ変換できない再登場にも対応が必要になる。
- 1時点だけ取り込み: 一部を再利用できるが、残りの時点を失う専用の移行操作が必要になる。

## 影響

旧JSONは初期モックで扱う。新形式では任意の時点ラベル・時点順序は保存しない。選択日は閲覧状態とし、ファイルを開いた際は最初の変更日、配置物がない場合は端末の当日を表示する。

判断を変更する場合は、新しいADRを作成し、本ADRの状態と置き換え先を更新する。
