# ADR 0004: アプリのバージョン管理

- 状態: 採用
- 決定日: 2026-09-26

## 背景

アプリの `package.json` にはバージョン番号があるが、変更履歴やリリースタグの運用は定めていなかった。また、プロジェクトJSONの形式バージョンとアプリのバージョンを区別する必要がある。

## 決定

- アプリのバージョンは `package.json` の `version` を正とする。
- 利用者に影響する変更を `CHANGELOG.md` に記録し、次回公開予定版の項目を公開時に日付付きの版項目として確定する。
- `0.x` の間は、新機能または互換性に影響する変更でマイナーバージョンを上げ、修正・ドキュメントのみの変更でパッチバージョンを上げる。
- `main` への反映とGitHub Pagesのデプロイ成功後に `vX.Y.Z` タグを作成する。未公開ブランチではリリースタグを作らない。
- プロジェクトJSONの `version` は別の形式バージョンとして扱い、保存形式の互換性に影響するときのみ変更する。

## 影響

次回公開予定版を `0.3.0` とする。リリース履歴は `CHANGELOG.md` とGitタグで追跡する。
