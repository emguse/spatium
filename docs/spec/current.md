# Spatium 現行設計仕様

この文書を現行動作の基準とします。初期計画は[履歴資料](../first-step.md)、未着手の機能案は[ロードマップ](../roadmap.md)、設計上の決定は[ADR](../decisions/)を参照してください。

## 目的と動作環境

Spatiumは、工場・倉庫の空間利用を日付ごとの2Dレイアウトで検討するブラウザーアプリです。図面・プロジェクトはブラウザー内で処理し、外部へ送信しません。PC版Chrome／Edge、マウスとキーボードを対象とします。

## 図面と配置

- PNG/JPEGの背景画像1枚を読み込み、既知距離の2点からmm/pxを校正します。グリッド間隔と原点を設定し、配置物の位置・寸法をグリッドに合わせます。
- 配置物は回転しない軸平行の長方形です。名称・幅・奥行き・色・メモは全期間共通です。固定物は別コレクションにあり、全期間共通の位置を持ちます。
- 選択日の配置物と固定物を編集できます。属性・寸法・位置の変更、複製、削除はUndo/Redoに対応します。固定物は専用モードで編集します。
- 背景画像・校正・グリッドは、配置物または固定物が登録されている間は変更できません。

## 日付・存在期間・位置

- 日付は実在する `YYYY-MM-DD` の日単位で扱い、時刻・タイムゾーンはありません。期間の開始日と終了日は両方含み、終了日未指定は無期限です。
- 1つの配置物が持つ存在期間は1つです。開始日に初期位置を持ち、後続の位置キーフレームは次のキーフレームまで引き継がれます。移動補間はしません。不在期間中は位置を編集できません。
- タイムラインは開始日・位置変更日・終了日・終了翌日を等間隔に並べます。存在帯、位置キーフレーム、終了日を区別し、任意の日付を選べます。
- 固定物は日付によらず常に存在します。配置物の複製は選択日の位置と共通属性から新しい配置物を作り、履歴・終了日は引き継ぎません。

## 重なり警告

- 選択日に存在する配置物と全固定物について、全ての組み合わせを判定します。長方形同士が正の面積で交差すると重なりとし、辺・角の接触だけは含めません。
- 対象の枠を赤い破線で強調し、キャンバスに干渉発生スタンプと重なりペア数、タイムラインの選択日に警告アイコンを表示します。図形のツールチップで相手の名称を確認できます。
- 警告は配置・保存を制限せず、PNG出力には含めません。全期間の重なり検索は行いません。

## ファイルと入出力

- プロジェクトJSON形式はversion 2です。背景・校正・グリッド・配置物と位置キーフレーム・固定物を保存します。アプリのバージョンとは独立して管理します。
- 読み込み時に値と参照を検証し、不正または非対応形式では現在のプロジェクトを置き換えません。version 1からの自動移行はしません。
- PNG出力は選択日の図面と配置物を含みます。キャンバス上の選択枠・警告表示・操作UIは出力しません。
- 自動保存はありません。JSONを利用者が保存し、開き直して復元します。Undo履歴はファイルに含めません。

## 現行版に含めないもの

任意ポリゴン、回転、同一配置物の複数存在期間、移動補間、自動再生、PDF入出力、部品パレット、共同編集、3D、任意プロパティ、工程データのインポートは現行仕様に含みません。機能案の扱いは[ロードマップ](../roadmap.md)に記録します。
