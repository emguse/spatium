# Spatium

工場・倉庫の空間利用を、時点ごとの2Dレイアウトとして編集するブラウザーアプリです。

## 起動

Node.js 22以降で、依存パッケージのインストールなしに起動できます。

```sh
npm run dev
```

http://127.0.0.1:5173 をChromeまたはEdgeで開いてください。配信サーバーはローカルホストにのみ接続し、図面・プロジェクトはブラウザー内で処理します。外部サービス、CDN、解析サービスは使用しません。`dist/` はビルド不要の静的ファイルです。

## 基本操作

1. PNG/JPEGの背景図面を読み込みます。
2. 「2点で縮尺を設定」で既知の距離の両端をクリックし、実寸をmmで入力します。
3. グリッド間隔（初期値100mm）と原点を設定します。
4. 「＋ 配置物」で長方形を作成し、名称・寸法・色・メモを入力します。位置・寸法の入力は最寄りのグリッドに丸めます。固定物は「固定物を編集」から作成します。
5. 時点を複製し、配置物を移動・追加・除去します。属性は全時点共通、位置と存在は時点ごとに独立します。
6. タイムラインのセルで時点と配置物を選択します。不在の配置物は「この時点に配置」から、キャンバスをクリックして再配置します。
7. 「保存」で背景を含むJSONをダウンロードします。「開く」で復元、「PNG出力」で選択中の時点を画像化します。

固定物は全時点共通で、専用モードでのみ編集できます。配置物が登録されている間は背景・校正・グリッド設定を変更できません。時点から除去しても配置物の定義は残るため、設定のロックも維持します。最初から設定し直す場合は新規プロジェクトを作成します。

- Ctrl/Cmd + Z: 元に戻す
- Ctrl/Cmd + Shift + Z: やり直す
- Ctrl/Cmd + S: 保存
- Delete / Backspace: 選択中の配置物を現在の時点から除去（固定物編集モードでは共通の固定物を削除）
- Esc: 校正・原点指定・再配置・ドラッグをキャンセル

自動保存はありません。保存表示はダウンロード要求時に更新します。ブラウザーのダウンロードが完了していることを確認してください。Undo履歴は直近100操作で、ファイルには保存しません。

## データと構成

- `dist/model.js`: データ操作、寸法校正、検証、Undo/Redo
- `dist/app.js`: SVGキャンバス、プロパティ、タイムライン、ローカル入出力
- `dist/style.css`: 作業画面のレイアウト
- `tests/model.test.js`: データモデルの回帰テスト
- `scripts/browser-check.mjs`: ブラウザーを使った一連の操作の回帰テスト

JSONの `version` は1です。`background` に画像とmm/pxの縮尺、`grid` に間隔と背景左上基準の原点、`entities` に共通属性、`fixed` に位置を含む共通固定物、`stages` に順序・ラベルとIDをキーにした `positions` を保存します。配置物の位置はグリッド原点を基準とします。背景の左上がX/Y=0、右が+X、下が+Yです。

画像は30MB以下・4,000万画素以下、プロジェクトファイルは60MB以下を受け付けます。PNG出力は図面と配置物を含む範囲を最大約4096pxに縮小し、余白と時点ラベルを付けます。遠くまでズームアウトするとグリッド表示を間引きますが、スナップ間隔は変わりません。

## 検証

```sh
npm test
npm run check
```

ブラウザーテストは、別途Playwrightを利用できる環境で、サーバー起動中に実行します。

```sh
node scripts/browser-check.mjs
```

Playwrightをローカル依存として導入しない場合は `PLAYWRIGHT_MODULE` にそのモジュールパスを指定できます。既存Chromeを使う場合は `CHROME_PATH` に実行ファイルを指定してください。テストは生成した模擬図面を使用し、スクリーンショットとPNGを `artifacts/` に保存します。

オプションのWebMCP対応ブラウザーでは、現在の時点・配置物の位置を読む `read_spatium_layout` を登録します。非対応ブラウザーでは通常のUIのみで動作します。

## 初期版の範囲

回転、移動補間、自動再生、PDF、部品パレット、衝突判定、共同編集、3Dは含みません。PC・マウス・キーボードを対象にしています。実際の工場・倉庫図面による業務検証は、利用者の図面を使って実施してください。
